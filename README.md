## Oyun

Her oyuncu küçük, yuvarlak bir mıknatıstır. Birbirinizin üstüne çıkar, anahtarı kapıya taşır,
aynı kutuptaki arkadaşını havaya fırlatır, zıt kutuptakini kendine çekersin. Bölüm, herkes kapıya girince biter.

Linki arkadaşına gönder, bilgisayardan ya da telefondan birlikte oynayın. 2 kişi yeter, 4 kişiye kadar olur.
Kendi bölümlerini editörde yapıp Atölye'de paylaşabilirsin.

## Kendi bilgisayarında çalıştırma

Node.js 18 ya da üstü gerekir.

```bash
npm install
npm start
```

Oyun `http://localhost:3000` adresinde açılır; `npm test` testleri çalıştırır.
